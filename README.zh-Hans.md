# FireAxe
**[English](README.md)** | **简体中文**

[下载](https://github.com/ktxiaok/FireAxe/releases)

FireAxe（旧称L4D2AddonAssistant）是一个开源的用于管理求生之路2模组的GUI工具。它有以下这些特性：
- 通过组的概念层级式地管理模组
- 支持下载创意工坊物品和合集
- 支持持续订阅创意工坊合集，自动同步新增与移除的 Mod
- 支持从 GameMaps 网址下载模组，自动解压 ZIP、RAR、7z 并导入其中的 VPK
- 模组启用状态管理
- 模组标签管理
- VPK冲突检测系统
- 模组优先级管理
- 模组依赖管理
- 模组问题检测系统
- 支持模组的导入和导出
- 本地VPK文件管理
- VPK信息显示
- 创意工坊物品信息显示
- 支持模组的搜索和过滤
- 支持引用模组来在不同的游玩方案之间快速切换
- ...

这个项目目前处于早期开发阶段，更多的功能将会在未来加入。

# 入门
- 在开始之前，你需要准备一个存储模组的文件夹。（注意：这个文件夹「不是」“left4dead2/addons”或者“left4dead2/addons/workshop”！)
- 打开FireAxe并点击菜单项“文件 -> 打开目录”来打开这个文件夹。
- 点击菜单项“文件 -> 设置”来设置你的游戏路径。
- 如果你有本地的VPK文件，把它们放在文件夹中。然后点击菜单项“文件 -> 导入”来导入它们。
- 如果你想要创意工坊的模组，右键打开上下文菜单然后点击“新建->创意工坊模组”。然后填写项目ID。FireAxe会自动下载你需要的文件。
- 如果你想要 GameMaps 的模组，右键选择“新建->GameMaps 模组”，填写详情页网址（如 `https://www.gamemaps.com/details/24878`）或项目 ID。下载进度会显示在下载列表中，下载完成后会自动解压并将所有 VPK 导入该模组组。也支持检测剪贴板中的 GameMaps 网址。下载失败时可点击“下载”或检查按钮重试；如被网站的 Cloudflare 拦截，可使用设置中的代理，或在浏览器下载后导入本地 VPK。
- 设置中的 GameMaps 区域位于创意工坊下方，可分别控制 GameMaps 项目自动更新和剪贴板链接检测。点击“检查”时，GameMaps 会根据文件更新时间、版本和文件信息检测新版；单个模组的三态自动更新策略及右键批量策略与创意工坊相同。也可在模组详情中点击“更新 GameMaps 项目”手动更新。更新会保留组与匹配 VPK 的名称、启用状态、标签等设置，并同步新增或移除的 VPK。
- 你可以创建一些组来管理模组。
- 启用你想启用的模组然后点击菜单项“操作 -> 推送”将启用状态推送到游戏。
- 你可以点击检查按钮来保持状态更新。

# 创意工坊合集订阅

- 右键选择“新建 -> 创意工坊合集订阅”，输入公开的求生之路 2 合集 ID 或网址。原有“创意工坊合集”仍为一次性导入。
- 订阅使用独立的叠卡图标和同步角标；可以像普通组一样管理启用状态、标签、优先级、依赖和引用。
- 与创意工坊模组一样，可以在详情中编辑合集 ID，或粘贴另一个合集链接更换来源。更换会取消旧来源的同步并立即读取新合集；读取成功后按下载、移除开关处理差异，保留新旧合集共有的 Mod 及其设置。新合集无效或不可访问时，现有 Mod 不会被删除。
- 程序打开模组目录时检查订阅，运行期间默认每 30 分钟自动同步。可以在“文件 -> 设置 -> 创意工坊合集订阅”中调整间隔，以及自动同步、允许下载、允许移除、新增 Mod 默认启用四个开关。自动同步只在 FireAxe 运行且目录打开时工作。
- 创建窗口和订阅详情中的三态开关可覆盖全局设置：方块为跟随全局、勾选为开启、空白为关闭。组的“全部”“单选”等启用策略仍然生效。
- 右键订阅选择“更新合集订阅”，或点击详情中的同名按钮，可随时手动同步。手动同步跳过自动同步开关，仍遵循允许下载、允许移除开关。
- 默认允许下载新增 Mod 和移除合集不再包含的 Mod。仅管理本订阅创建且仍在本组中的创意工坊 Mod；手动加入的内容、GameMaps 模组和移到其他组的 Mod 不会被同步删除。手动删除或移出的 Mod 在离开远端合集前不会被反复下载回来。
- 移除文件沿用软件现有机制：Windows 下移入回收站，其他平台按现有删除方式处理。引用这些 Mod 的其他节点也遵循软件现有的引用失效处理。已有 Mod 的名称、启用状态、标签、优先级等设置会保留，文件更新遵循各 Mod 自己的创意工坊自动更新策略。
- 支持关联合集、循环检测和重复 Mod 去重；请求失败、私密合集或不完整响应不会被视为空合集。保存、重启以及 `.addonroot` 导入导出均保留订阅来源与管理记录。
- 这是 FireAxe 本地订阅，不会修改 Steam 账号的订阅列表。合集读取使用 [Steam 官方 GetCollectionDetails 接口](https://partner.steamgames.com/doc/webapi/ISteamRemoteStorage#GetCollectionDetails)。启用所需订阅及 Mod 后，仍需“推送”到游戏。

# 常见问题解答
## 为什么我在游戏里看不见我的模组？
请确保你的模组自身启用并且模组所在的所有组都启用，确保你点击了推送按钮。
如果在推送之前游戏已经在运行了，你需要在推送后在游戏菜单内刷新模组。

## 最好的将我在创意工坊订阅的模组迁移至FireAxe的方式是什么？
你可以使用工具菜单中的创意工坊VPK查找器。

## 在迁移之后我需要取消在创意工坊的订阅吗？
需要。FireAxe不会管理在创意工坊订阅的模组。

## 如何解决推送失败的问题？
请确保你的文件系统是NTFS或任何其他能创建符号链接的文件系统。

## 优先级系统是怎样运作的？
对于多个VPK中存在的相同名称的文件，游戏最终会加载优先级最高的文件。
每个模组有它自身的优先级和全局优先级。
全局优先级是模组自身的优先级与模组所在的所有组的优先级的和。
最终起效果的是全局优先级。
举个例子，如果你想添加一批新的模组并覆盖当前的模组，你可以把这些模组放进一个组中并给组设置一个更高的优先级。

## 我该如何使用引用模组？
一个引用模组是对另外一个模组的引用，具有它自身的启用状态和优先级。
举个例子，你可以给一批模组创建一批引用模组，这实际上就相当于配置了另外一个游玩方案并且可以在不同的方案之间快速切换。

## .addonroot文件的导入导出的用途是什么？
.addonroot是FireAxe用来存储模组信息（如启用状态、创意工坊ID等）的一种文件格式。
举个例子，你可以将一批创意工坊模组导出为一个.addonroot文件并分享给你的朋友。
你的朋友可以一键导入这个文件来获得你导出的这批模组。
